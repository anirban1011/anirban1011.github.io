# anirbanrouth.in

Personal portfolio of Anirban Routh, a full-stack developer from West Bengal, India.

Plain HTML, CSS and JavaScript. No build step and no frameworks.

## Structure

| Path | What it is |
|---|---|
| `index.html`, `about.html`, `projects.html`, `contact.html` | Main pages |
| `sms-forwarder.html`, `kuberkosh.html` | Project pages |
| `assets/css/style.css` | All styles |
| `assets/js/site.js` | Mobile menu and contact form |
| `images/` | Photos, screenshots and social cards |
| `CNAME` | Custom domain (anirbanrouth.in) for GitHub Pages |

## Contact form

The form on `contact.html` sends mail through [EmailJS](https://www.emailjs.com/). The keys are set at the top of `assets/js/site.js`. If sending fails, visitors are shown a direct email address.

## Hosting

Deployed with GitHub Pages from the `main` branch, root folder.
